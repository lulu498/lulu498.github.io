## 本次改变

- 首页视频封面改为预生成的 WebP 图片，浏览列表不会下载视频。
- 项目里点击播放后才加载视频，同一时间只播放一段。
- 默认使用适合在线播放的 H.264/AAC MP4；全部默认播放文件已将播放索引移到文件前部。
- 可以选择“流畅”或“原画”，切换时保留当前播放位置；“下载原片”对应原始文件。
- 关闭项目会停止视频并释放加载；切到后台或把视频滚出屏幕会暂停。
- 保留声音、完整时长和原始画面比例；不裁切内容。部分高帧率素材的流畅版最高为 30fps，原画保持原文件。
