作品完整，
分享轻一点。

导入完整 HTML 或 .tar 备份，在作品左侧点击「编辑项目说明」，填写背景、职责、周期、难点和成果。右侧封面统一尺寸；点击可查看完整图片与视频。填写后保存可编辑版，或导出投递版。

文件只在本机读取，不会上传。转换大文件请在电脑浏览器完成。
手机分享建议导出网页包，发布后发链接；单文件版仍需支持 HTML 的浏览器打开。

压缩分享副本

建议先选「强力压缩」。还嫌大可选「极小文件」，但 UI 小字、纹理和视频会明显变糊。视频默认参与压缩，不裁画面、不删片段；原文件另存保留。

强力：图片最长边 1440px，视频约 540p。极小：图片最长边 1080px，视频约 360p。实际大小取决于作品数量、视频时长和浏览器支持；动态图片保留原文件。
